# Examples

The public example is in [simulated/](simulated/README.md). It supplies three
synthetic chr22 samples and reference inputs for an end-to-end PennCNV and
CNValidatron run. No participant signal values or genotypes are used.

From the repository root, activate the analysis
environment and supply a compatible downloaded model:

```bash
conda activate penncnv-cnvalidatron
bash full_pipeline/examples/run_example.sh --model /path/to/joint.rds --check
bash full_pipeline/examples/run_example.sh --model /path/to/joint.rds
```

Use `--output NEW_DIRECTORY` to repeat the run in a fresh location. Results
are generated by the user and excluded from Git.

For your own samples, copy the templates under `config/` and `metadata/` and
follow the [real-run instructions](../README.md#set-up-a-real-run). Each batch
receives a separate PFB and output directory. All coordinate inputs must already
share a genome build; no liftover is performed.
