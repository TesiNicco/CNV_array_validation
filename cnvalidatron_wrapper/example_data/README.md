# Wrapper examples

Choose the step you want to test:

- **[before_preparation/](before_preparation/README.md)**: raw synthetic signals,
  SNP/sample tables and PennCNV-format simulated calls. Run `preparation.R` to
  convert and index them, then optionally run parallel validation.
- **[after_preparation/](after_preparation/README.md)**: portable reference tables
  showing the expected output schema from preparation. Actual signal copies and
  indexes are generated by the user.
- **[simulated/](simulated/README.md)**: validation-ready synthetic signals and
  fixed CNV tables. Use `run_example.sh --model MODEL.rds` to test the direct
  validation worker without the standalone preparation or parallel launcher.

All examples use the same independently simulated chr22 values, with a
fixed deletion and duplication. No participant measurements are included.
Prepared files, indexes and predictions are generated at execution time and
are not distributed.
